Contabilidad · Gestión comercial

Sistema Darjam

Sistema contable y de ventas para una perfumería de perfumes originales y decants (venta por mililitro).

  • Reemplacé el libro de Excel "DARJAM ANUAL" por una aplicación web multiusuario, migrando todo el histórico y reproduciendo su lógica contable.
  • Caja, Banco y Patrimonio se calculan en tiempo real desde 7 vistas SQL; ningún saldo se guarda precalculado, así no quedan desactualizados.
  • Cubre ventas con pago combinado, compras por lotes, gastos, comisiones por vendedor, activos fijos, deudas, adelantos, sueldos y operaciones en USDT.
  • Control de acceso por roles: el vendedor nunca ve costos, márgenes ni resultados globales. Tienda pública con disponibilidad indicativa, sin stock exacto.
  • Catálogo de alta variación y respaldos automáticos en producción (mysqldump). Seguridad con bcrypt y consultas preparadas PDO.
  • Documentación técnica de 27 páginas con requerimientos, diccionario de datos, matriz de permisos, plan de pruebas y 4 diagramas.

Logística · Operaciones

Anglotrax

Plataforma web de gestión logística, desplegada en producción en anglotrax.cloud.

  • Módulo de tarja para registrar y controlar la carga en cada operación, con carga de archivos y evidencias desde el navegador.
  • Despliegue y mantenimiento en servidor propio: configuración de producción, límites de subida, permisos de almacenamiento y lectura de logs para resolver errores 500.
  • Junto a Plataforma Andina: refactorización de la base de datos desde un modelo de planificación estratégica (PEI/PDI) a un modelo dinámico de gestión presupuestaria.
  • CRUDs con DTOs, reportes complejos y exportación a Excel para el área operativa.
